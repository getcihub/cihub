# What's CIHub?

**CIHub** is a platform that dynamically creates GitHub Actions runners on bare metal servers using Firecracker microVMs. It adapts to your CI workflows by provisioning ephemeral, isolated, and high-performance runners on demand—ensuring secure, reproducible, and cost-efficient builds without sacrificing speed.
